# 嵌入式 环境配置 - Linux

请根据所使用的 Linux 发行版，自行搜索并安装以下组件：

- Git
- GitHub CLI（`gh`）
- GNU Make（`make`）
- CMake
- Ninja
- Arm GNU Toolchain（`arm-none-eabi-gcc`、`arm-none-eabi-g++`）
- Visual Studio Code
- [STM32CubeMX](https://www.st.com/en/development-tools/stm32cubemx.html)
- [SEGGER J-Link](https://www.segger.com/downloads/jlink)
- [SEGGER Ozone](https://www.segger.com/downloads/jlink#Ozone)
- [SEGGER SystemView](https://www.segger.com/downloads/jlink#SystemView)

请选择适用于你所使用的 Linux 发行版和系统架构的安装包。安装过程中如遇到问题，请联系我们。
