# 硬件部门 Tutorial

## 软件安装

### KiCad

下载并安装 **KiCad 9.0.3**。请选择与当前操作系统和架构对应的安装包。

**下载版本9.0.3！不要下载最新版。**

[KiCad 官方下载页面](https://downloads.kicad.org/kicad/windows/explore/stable)

### STM32CubeMX

在 ST 官网登录或注册账号，然后下载并安装适用于当前操作系统和架构的 **STM32CubeMX 最新版** 。

**请勿安装 STM32CubeMX2。**

[STM32CubeMX 官方下载页面](https://www.st.com.cn/zh/development-tools/stm32cubemx.html)
